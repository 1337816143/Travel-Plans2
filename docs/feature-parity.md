# Web 与小程序功能一致性

功能一致不等于页面布局完全相同。两端必须共享相同的业务能力、数据结果和规划规则，只允许针对屏幕尺寸、导航方式、平台权限和地图 SDK 调整交互外壳。

首批一致性清单：

| 能力 | Web | 小程序 | 验收标准 |
|---|---:|---:|---|
| 地图搜索与选点 | 必须 | 必须 | 搜索结果可加入同一旅行 |
| 预设攻略浏览 | 必须 | 必须 | 地点、来源和动态提示一致 |
| 地图标记样式 | 必须 | 必须 | 图标语义、颜色和编号一致 |
| 地点分组/分批 | 必须 | 必须 | 分组可同步并批量显示隐藏 |
| 拖拽调整日程 | 必须 | 必须 | 调整后仅重算受影响部分 |
| 住宿与跨城方案 | 必须 | 必须 | 使用同一分析结果和解释 |
| 社区反馈 | 必须 | 必须 | 固定标注“来自旅行者反馈” |
| 路线样式和备注 | 必须 | 必须 | 线型、粗细、方向和备注可编辑 |
| 分享、导出、打印 | 必须 | 等价流程 | 小程序可生成分享卡片或文件 |
| 离线草稿 | 必须 | 必须 | 断网编辑后可恢复和同步 |

新增功能必须先更新本表和共享验收用例，再进入任一端开发。若平台原生能力不同，应提供等价流程，不得静默删减功能。
